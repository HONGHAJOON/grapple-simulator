# 집게차 시뮬레이터 v0.1

개인용 1인칭 웹 프로토타입. Vue 3 / TypeScript / Vite / Three.js. 서버와 DB 불필요.

## Windows 실행
Node.js 22 LTS 이상 설치 후 PowerShell 또는 CMD에서:

```powershell
cd C:\DEV\PROJECT\cu\grapple-simulator
npm install
npm run dev
```
브라우저 http://localhost:5173 접속. 동일 Wi-Fi 스마트폰은 터미널에 출력되는 Network 주소로 접속(Windows 방화벽의 개인 네트워크 허용 필요). 외부 네트워크에서 쓰려면 `npm run build` 결과인 dist 폴더를 정적 호스팅에 배포.

## 조작
- 화면 드래그: 시선 이동. 정면 버튼으로 초기화.
- 하단 레버를 위/아래 드래그. 손을 떼면 중립. 여러 손가락 동시 조작 지원.
- 키보드: 왼쪽부터 위/아래 순으로 Q/A 집게, W/S 집게 회전, E/D 신축 붐, I/K 아우터 붐, O/L 메인 붐, P/; 스윙.
- 초기에는 집게가 열린 상태. 스윙으로 우측 폐기물 방향을 향하고 붐을 조절해 집게 중앙을 물체에 가까이 가져간 뒤 A로 닫고, 적재함 위에서 Q로 연다.

## 범위 및 제한
- 모델은 기본 도형을 조합한 가상 장비이며 제조사 공식 모델이 아니다.
- 파지는 거리 기반 근사, 낙하는 단순 중력과 바닥/적재함 판정. Rapier, 실제 충돌, 폐기물끼리 쌓임, 실제 유압 및 하중 제한은 아직 미구현.
- 레버 방향/배치 및 장비 제원은 실제 광림 장비와 일치한다고 보장하지 않는다. 실제 장비 운전 교육이나 안전 판단에 사용하지 않는다.
- 모바일 브라우저 가로 화면 권장. 실제 기기별 성능 테스트 필요.
